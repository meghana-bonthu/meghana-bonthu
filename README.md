### 🎮 QuizBattle — Real-Time Multiplayer Quiz Platform

A full-stack **real-time multiplayer quiz application** featuring multiplayer rooms, synchronized timed gameplay, server-side answer validation and scoring, real-time results, and live leaderboards.

The application uses a **server-authoritative architecture** to synchronize game state across connected clients while preventing duplicate, invalid, and late answer submissions.

**Highlights:**
- Real-time multiplayer rooms and player presence
- SignalR-based communication
- Synchronized timed questions
- Server-side answer validation
- Real-time scoring and result updates
- Live leaderboards
- SQL Server persistence
- Dockerized database environment

**Tech Stack:** C# • .NET 8 • ASP.NET Core • SignalR • React • TypeScript • Entity Framework Core • SQL Server • Docker
